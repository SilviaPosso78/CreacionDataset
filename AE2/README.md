# AE2: Manejo de archivos CSV, JSON y TXT

## Fuentes (descarga manual desde Hugging Face)
- CSV: https://huggingface.co/datasets/scikit-learn/iris/blob/main/Iris.csv
- JSON: https://huggingface.co/datasets/sahil2801/CodeAlpaca-20k/blob/main/code_alpaca_20k.json

## Archivos
- `manejador_csv.py`: clase para importar, modificar y guardar CSV.
- `manejador_json.py`: clase para importar, modificar y guardar JSON.
- `generador_resumen_txt.py`: clase que genera `resumen.txt`.
- `AE2.ipynb`: notebook que coordina el flujo.
- `Iris.csv`, `code_alpaca_20k.json`: archivos originales.
- `Iris_modificado.csv`, `code_alpaca_20k_modificado.json`: archivos modificados.
- `resumen.txt`: resumen generado.

## Pasos de ejecución
1. Abrir `AE2.ipynb` en Jupyter o Google Colab.
2. Colocar `Iris.csv` y `code_alpaca_20k.json` en la misma carpeta del notebook.
3. Ejecutar todas las celdas en orden.
